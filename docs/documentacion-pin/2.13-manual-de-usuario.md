## Acceso al sistema

1. Pantalla de registro (`registro.js`) — capturar formulario vacío y completado.
2. Pantalla de login (`login.js`) — capturar formulario y mensaje de error ante
   credenciales inválidas (para mostrar manejo de errores).

## Uso de funcionalidades

Para cada una, capturar la pantalla principal + un flujo completo de 2-3 pasos:

- **Adoptar** (`adoptar.js`): catálogo con filtros → ficha de una mascota → clic en
  "Adoptar" → chat creado con el dueño.
- **Mascotas perdidas** (`mascotas-perdidas.js`): mapa con pines → formulario de reporte
  → mascota nueva visible en el mapa.
- **Comunidad** (`comunidad.js`): feed de publicaciones → crear post → comentar/dar like.
- **Historias de éxito** (`historias.js`): listado → detalle de una historia.
- **Carnet digital** (`carnet.js`): ficha completa de una mascota con datos médicos y
  veterinario.
- **Chats** (`chats.js`): lista de conversaciones → una conversación abierta.
- **Perfil** (`perfil.js`): edición de datos y foto.
- **Asistente de IA** [PENDIENTE hasta que esté implementado — ver 2.10]: capturar una
  conversación completa de recomendación.

## Lenguajes de programación

- JavaScript (Node.js en el backend, vanilla JS en el frontend — sin framework como
  React/Vue; el frontend es multipágina con módulos JS por sección).

## Frameworks y librerías principales

| Capa | Tecnología | Uso |
|---|---|---|
| Backend | Express 4 | Servidor HTTP y ruteo de la API |
| Autenticación | jsonwebtoken + bcryptjs | Tokens de sesión y hash de contraseñas |
| Base de datos | pg (node-postgres) | Cliente de PostgreSQL |
| Frontend | Vanilla JS + HTML/CSS | Sin framework — páginas en `frontend/js/pages/` |
| Mapas | Leaflet + OpenStreetMap | Mapa de mascotas perdidas |
| PDF/automatización | Puppeteer | [confirmar uso exacto — probablemente generación de PDF del carnet digital] |

## Infraestructura

- **Hosting:** Vercel — despliega el backend como función serverless
  (`backend/server.js`) y el frontend como sitio estático, ruteados según
  `vercel.json` (`/api/*` → backend, resto → frontend).
- **Base de datos:** PostgreSQL gestionado por Supabase (migrado desde SQLite local,
  ver historial de commits — `d893de1`).
- **Variables de entorno:** `DATABASE_URL`, `JWT_SECRET`, `PORT` (opcional, default
  3000). Ninguna credencial vive en el repositorio (`.env` está en `.gitignore`).

## Integraciones

- **Mapas:** Leaflet / OpenStreetMap (activa).
- **Inteligencia Artificial:** planeada, no integrada todavía — ver apartado 2.10.
  Cuando se implemente, documentar acá: proveedor elegido, modelo, y cómo se conecta el
  agente a la base de datos real de mascotas (requisito valorado por la consigna, para
  que las recomendaciones no sean inventadas).
